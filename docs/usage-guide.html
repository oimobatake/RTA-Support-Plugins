OBS STUDIO PLUGIN / 利用ガイド

RTA Support Plugin
使い方ガイド

RTA イベントの配信で、タイマー・ゲーム情報・走者名・次のゲームを OBS のドックから操作して画面に出すためのプラグインです。NodeCG を用意するほどではない規模のイベントで、情報の切り替えを手早く行うことを目指しています。このページでは、インストールから本番当日の操作までを図を交えて説明します。

  • Windows 64bit
  • OBS 30.1〜32.2 対応
  • 表示は Browser ソース（1920×1080）
  • 設定ファイルは UTF-8 の JSON

01しくみ

最初に全体像を押さえておくと、後の設定で迷いません。

操作はすべて OBS の中のドック「RTA Support Plugin」で行います。ドックで何かを変えるたびに、プラグインは overlay_data.json というファイルに最新の内容を書き出します。配信画面に表示しているのは Browser ソースで読み込んだ index.html で、このページが 0.1 秒ごとに JSON を読み直して文字を描き直します。

このため、index.html と overlay_data.json は同じフォルダに置く必要があります。プラグインが JSON を書き出す場所は決まっているので、index.html をそこへコピーするのがいちばん簡単です（次の章で説明します）。

02インストール

置くファイルは 2 つです。プラグイン本体の DLL と、表示用の index.html。

  1. OBS を終了する起動中は DLL を差し替えられません。タスクトレイに残っていないかも確認してください。
  2. DLL をプラグインフォルダにコピーするbuild_x64\rundir\Release\RTA-Support-Plugin.dll を C:\Program Files\obs-studio\obs-plugins\64bit\ に置きます。OBS を別の場所にインストールしている場合は、その中の obs-plugins\64bit です。管理者権限の確認が出たら許可してください。
  3. OBS を起動してドックを表示するメニューの「ドック」に RTA Support Plugin が増えているので、チェックを入れて表示します。好きな位置にドッキングしておきましょう。
  4. 一度だけ保存操作をするMain タブで何か入力して done を押すと、設定フォルダに overlay_data.json が作られます。
  5. index.html を設定フォルダにコピーするリポジトリの resource\index.html を、%APPDATA%\obs-studio\plugin_config\RTA-Support-Plugin\（いま作られた overlay_data.json と同じ場所）に置きます。

普段の配信用とは別に、イベント専用のシーンコレクションを作ってその中で使うのがおすすめです。普段のシーンを崩さずに済みます。

03OBS に表示する

配信画面に文字を出すのは Browser ソースの役目です。

  1. シーンに「ブラウザ」ソースを追加するソース一覧の ＋ から「ブラウザ」を選びます。
  2. 「ローカルファイル」にチェックを入れて index.html を選ぶ前の章で設定フォルダに置いた index.html を指定します。
  3. 幅 1920・高さ 1080 にする配置の座標はすべて 1920×1080 の画面を基準にしています。ソースは画面全体に重ねてください。
  4. （必要なら）カスタム CSS でレイアウトを指定する何も書かなければ main レイアウトで表示されます。待機画面など別のレイアウトを使う方法はレイアウトの使い分けで説明します。

ここまでで、ドックの内容が配信画面に出る状態になります。文字が出ないときは困ったときを見てください。

04Main タブ　本番中に触る画面

タイマーと、いま走っているゲームの情報を操作します。本番中はほぼこのタブだけで完結します。

  • 1
    タイマー表示　左がカウントアップ、右がカウントダウンです（どちらも 時:分:秒）。カウントダウンの初期値は右の欄に入力して done を押すと記録され、Reset でその値に戻ります。
  • 2
    Start で計測開始、Stop で停止、Reset でカウントアップは 0、カウントダウンは初期値に戻ります。計測中は done と ▲▼ が押せなくなり、誤操作で表示が切り替わるのを防ぎます。
  • 3
    表示モード　カウントアップのみ／カウントダウンのみ／両方／非表示 から選びます。
  • 4
    ゲーム選択　プルダウンで選ぶと、そのゲームの情報が下の入力欄に読み込まれます。▲▼ を押すと前後のゲームに切り替わり、そのまま画面にも反映されます。プルダウンで選んだときは、確認してから done を押します。
  • 5
    ゲーム情報　タイトル・カテゴリ・機種・予定時間を手で直せます。タイトル欄の右端の A ボタンは、文字の一部だけ大きさや色を変える機能です（後述）。
  • 6
    走者と個人タイム　並走では各走者の Stop を押すと、その瞬間のカウントアップの値が「走者タイマー」として記録されます。カウントアップが表示されているモード（TimerOnly か Both）で使ってください。記録は Reset で消えます。
  • 7
    done で入力欄の内容を確定し、画面に反映します。

停止中のタイマーの文字色は Global タブの「TimerStopColor」で決まります。計測中は Design タブで設定した色で表示されます。

05Schedule タブ　スケジュールの取り込み

イベントの走順を JSON で読み込んでおくと、本番中は ▲▼ を押すだけで次のゲームに切り替えられます。

読み込める JSON の形

列名の一覧 columns と、各ゲームの行 items を持つ形式です。length_t は予定時間（秒）です。

{
  "schedule": {
    "columns": ["Game", "Category", "Platform", "Runner", "Commentary"],
    "items": [
      { "data": ["Super Mario 64", "120 Star", "N64", "ばたけ", "解説者A"], "length_t": 6300 },
      { "data": ["ドンキーコング64", "Any%", "N64", "走者1, 走者2", ""],     "length_t": 5400 }
    ]
  }
}
  • 読み込むと、列名のキーワードから「どの列がタイトルか」などが自動で推測されます。Column Format の 5 つのプルダウン（GameTitle / Category / Platform / RunnerName / Commentator）で正しいか確認し、違っていれば選び直してから apply を押します。
  • 並走など走者が複数いるときは、走者の欄に カンマ区切りで書きます。左から順に Runner1〜4 に入ります。
  • スケジュールは保存され、OBS を再起動しても残ります。
  • ファイルは必ず UTF-8 で保存してください。

配信画面の「次のゲーム1〜3」には、いま選んでいるゲームの次から 3 件が自動で入ります。待機画面で次の予定を見せたいときに使えます。

06Design タブ　見た目と配置

画面に出す文字（パーツ）ごとに、位置・フォント・色などを決めます。設定は「レイアウト」単位でまとめて保存されます。

パーツは全部で 30 個あります。

分類パーツ
ゲーム情報ゲームタイトル、カテゴリ、ハードウェア、予想時間
タイマーカウントアップ、カウントダウン、走者タイマー1〜4
走者・解説走者名1〜4、解説者
次のゲーム1〜3それぞれ タイトル・走者・カテゴリ・ハード・予定時間

細かい数値で調整する

Design タブの「TextName」で編集するパーツを選び、次の項目を設定します。ふだんの配置はビジュアルエディタの方が速いので、こちらは数値をきっちり合わせたいときに使います。

項目内容
TextFont / TextColorフォント（種類・大きさ・太字・斜体）と文字色
TextPositionX / Y 座標（1920×1080 基準）。ここで座標を入れたパーツは「配置済み」になります
揃え左・中央・右。中央揃えなら X は文字の中心、右揃えなら右端の位置になります
outline縁取りの有無・太さ・色。背景が明るい場所で読みやすくなります
TextMaxWidth / WrapMode最大幅（0 は制限なし）と、はみ出したときの扱い（制限なし／自動縮小／自動改行）。長いタイトル対策に便利です

レイアウトの管理

  • Add いまのレイアウトを元に新しいレイアウトを作ります。新しいレイアウトは全パーツ「未配置」から始まります。
  • Delete 選択中のレイアウトを削除します（確認あり）。
  • SaveLayout / LoadLayout レイアウトを JSON ファイルに書き出し／読み込みします。バックアップや別 PC への移行に使います。
  • SyncSceneChange にチェックを入れると、レイアウトを切り替えたときに同じ名前の OBS シーンにも切り替わります。

07ビジュアルエディタ　画面を見ながら配置

Design タブの「ビジュアルエディタ」ボタンで開きます。配信画面と同じ 1920×1080 のキャンバスに、パーツを置いていく方式です。

覚えておきたいこと

  • 未配置のパーツは OBS に表示されません。使わないパーツは置かなければ出ません。置いたものを消したいときは Delete か右クリック「配置を外す」で一覧に戻します。
  • 一時的に隠したいだけなら、プロパティの「OBSに表示する」のチェックを外します（配置は残ります）。
  • キャンバスには実際の文字が、設定中のフォント・色・縁取りで表示されます。空のパーツは「Super Mario 64」のような仮の文字で表示されます。
  • 複数選択（Ctrl+クリック、または範囲ドラッグ）すると、まとめて移動・スタイル変更・整列ができます。
  • 「背景画像」でフレーム画像などを敷いて、それに合わせて配置できます。背景はエディタ内だけの表示で、OBS には出ません。

「配置」メニュー

メニュー内容
1人走（右側に情報欄）右側にタイトル・カテゴリ・機種・予定時間・走者・タイマー・解説を縦に並べます
2人並走左右に走者名と走者タイマー、中央にタイマー、下にタイトル・カテゴリ・解説を置きます
4人並走（4分割）4 分割の各画面の下に走者名と走者タイマー、中央にタイマーを置きます
待機画面（次のゲーム3件）上に現在のタイトル・カテゴリ、その下に次のゲーム 1〜3 のタイトル・カテゴリ・走者・予定時間を並べます
別レイアウトから複製他のレイアウトの配置をそのまま取り込みます
すべて未配置に戻すやり直したいときに使います

プリセットで大まかに並べてから、ドラッグで微調整するのが早いです。

08タイトルの一部だけ大きさや色を変える

「Super Mario 64」のように、ゲームタイトルの一部だけ小さくしたり色を変えたりできます。

  • 使えるのは 大きさ（% 指定）・色・太字 です。大きさは要素のフォントサイズに対する割合なので、Design タブで基本の大きさを変えても比率は保たれます。
  • 装飾をやめたいときは、文字を選んで「装飾をすべて解除」を選びます。
  • ゲーム選択のプルダウンには、タグを除いた文字が表示されます。
  • スケジュール JSON のタイトルに同じタグを書いておけば、読み込んだ時点から装飾付きで表示されます。

09レイアウトの使い分け

「プレイ中」と「待機画面」のように、シーンごとに配置を変えたいときの設定です。

どのレイアウトで表示するかは、Browser ソースごとにカスタム CSS で決めます。シーンごとに Browser ソースを置き、それぞれに使いたいレイアウト名を書いておけば、シーンを切り替えるだけで配置も切り替わります。

  1. Design タブでレイアウトを作るAdd で例えば setup を作り、ビジュアルエディタで「待機画面（次のゲーム3件）」プリセットを当てます。
  2. 待機画面のシーンに Browser ソースを追加する設定は OBS に表示する と同じです。
  3. カスタム CSS にレイアウト名を書くBrowser ソースのプロパティの「カスタム CSS」に body { --rta-layout: setup; } を追記します。何も書かないソースは main で表示されます。

レイアウト名と OBS のシーン名を同じにしておき、Design タブの SyncSceneChange をオンにすると、ドックでレイアウトを切り替えたときに OBS のシーンも同じ名前のものに切り替わります。

10Global タブ　全体の設定

項目内容
Runner1〜4_Icon / Commentary_Icon走者名・解説者名の前にアイコンを付けます。名前が空のときは表示されません
AutoScreenShotFlagTimerStart / TimerStop にチェックすると、タイマー開始時・停止時に OBS のスクリーンショットを自動で撮ります。記録の証拠用に便利です
TimerStopColorタイマー停止中の文字色
ScreenShot押した瞬間にスクリーンショットを撮ります

スクリーンショットは OBS の録画と同じ保存先に作られます。事前に保存先と空き容量を確認しておいてください。ここでの設定は保存され、再起動後も残ります。

11本番当日の流れ

ふだんの操作は Main タブの数ボタンだけです。

前日まで

スケジュール JSON を読み込み、レイアウトを作って配置を決めます。Browser ソースで表示を確認し、Export と SaveLayout でバックアップを取っておきます。

開始前

最初のゲームをプルダウンで選んで done。表示モードとカウントダウンの初期値を確認し、Reset でタイマーを 0 にします。

走行開始

Start。自動スクリーンショットがオンなら、この時点で 1 枚撮られます。

走行中

並走なら、走者がゴールした順に各走者の Stop を押して個人タイムを記録します。

完走

全体の Stop。停止色に変わったタイムがそのまま画面に残ります。

次のゲーム

Reset してから ▼。次のゲームの情報が読み込まれ、画面にもすぐ反映されます。必要ならシーンを待機画面に切り替えます。

計測中は ▲▼ と done が押せません。次のゲームへ進む前に、必ず Stop → Reset の順で止めてください。

12困ったとき

ドックのメニューに RTA Support Plugin が出てこない

DLL の置き場所を確認してください。obs-plugins\64bit の中に RTA-Support-Plugin.dll があるか、OBS を完全に終了してから置いたかを見直します。このプラグインは OBS 30.1〜32.2 向けです。30.0 以前の OBS では読み込まれません。

Browser ソースに何も表示されない

index.html と overlay_data.json が同じフォルダにあるか確認してください。overlay_data.json がまだ無い場合は、ドックで一度 done を押すと作られます。パーツがビジュアルエディタで「未配置」のままだと表示されないので、配置済み（緑の丸）になっているかも確認します。

待機画面用のソースが main の配置で出てしまう

カスタム CSS の書き方を確認してください。body { --rta-layout: setup; } のように body に対して書き、レイアウト名はドックの表示と大文字・小文字まで一致させます。

スケジュールを読み込んだら文字化けした

JSON を UTF-8 で保存し直して、もう一度読み込んでください。

走者タイマーが空欄のまま

表示モードが CountDownOnly か None になっていると、走者の Stop を押しても記録されません。TimerOnly か Both にしてください。

長いタイトルが画面からはみ出す

Design タブかビジュアルエディタのプロパティで最大幅を設定し、はみ出したときの扱いを「自動縮小」か「自動改行」にします。

設定をバックアップ・別の PC に移したい

レイアウトは SaveLayout、スケジュールは Export で書き出せます。すべてまとめて移すなら、設定フォルダの overlay_data.json をコピーします。
