# **RTA Support Plugin**

OBS Studio上でRTAイベント等の進行を支援するためのプラグインです。

「NodeCGでレイアウトとか用意するほどじゃないな…」 とか 「NodeCGとかわかんないけどあんな感じにサクッと情報変更したいな」
みたいな時に使えるようなものを目指して作りました。

タイマー操作、テキストソースの自動生成、スケジュールの管理を一括で行うことができます。

## **🛠 1\. 導入方法**

本プラグインを正常に動作させるには、以下の手順でファイルを配置してください。

### **① プラグインファイルの配置**

**RTA-Support-Plugin.dll** を、OBSのインストールフォルダ内の以下のディレクトリにコピーします。

**パス:** C:\\Program Files\\obs-studio\\obs-plugins\\64bit\\

### **③ OBSの起動**

OBSを起動し、上部メニューの **\[ドック\]** ＞ **\[RTA Support Plugin\]** を選択してパネルを表示させてください。

## **📖 2\. 使い方**

プラグインは3つのタブで構成されています。

### **🟦 Main タブ（基本操作）**

配信中に最も頻繁に使用するメイン画面です。

* **タイマー操作**
  * **Timer**: いつものタイマーです
  * **CountDownTimer**: カウントダウンタイマーです。制限時間を設けたい時にどうぞ(現状超長時間には対応してないので許してください)
  * **Start**: タイマーを開始します。  
  * **Stop**: タイマーを一時停止します。  
  * **Reset**: タイマーを初期値（00:00:00）に戻します。
  * **TimerOnly**: Timerのみ動作します。
  * **CountDownOnly**: CountDownTimerのみ動作します。
  * **Both**: ↑二つがどっちも動作します。
 
* **各種情報**
  * **ドロップダウンリスト**: スケジュールを読み込んだ際にゲームタイトルの一覧が表示されます。これを変更するとGameTitleなんかの情報が一気に入ります。
  * **GameTitle**: ゲームタイトル
  * **EST**: 予定時間
  * **Category**: RTAのカテゴリーです(Any%とか)
  * **Hardware**: 機種です(SFCとかPSとか platformで良かったかも)
  * **Runner**: 走者名 最大四人まで対応しています。
  * **走者名横Stopボタン**: 並走時など、本体のタイマーを止めないで各走者のタイマーストップする際に使用します。
  * **Commentary**: 解説者名
  
* **Done ボタン**  
  * このボタンを押すと、シーンに必要な**テキストソースがすべて自動で作成**されます。  
  * 作成されるソース例: GameTitle, RunnerName\_1, CountUpTimer 等。  
  * すでにソースが存在する場合は、新規作成をスキップして内容の更新のみ行います。

### **🟩 Info タブ（スケジュールの読み込み）**

外部のスケジュールデータ（JSON形式）を取り込みます。

1. **ファイルの読み込み**  
   * Select JSON ボタンから、スケジュールの情報が記載された .json ファイル を選択します。  
2. **カラム設定 (Column Format)**  
   * 読み込み後、各要素（ゲーム名、走者、カテゴリ等）が何を表しているかを指定するリストが表示されます。  
   * Horaro等で設定した項目名が出てくるので、内容に合わせて選択してください。  
3. **適用 (Apply)**  
   * 適切な項目を選択して Apply を押すと、スケジュールがMainタブへ読み込める状態になります。  
   * ※初期状態はすべて「Runner」になっている場合があるため、必ず各項目を確認・変更してください。

### **⚙️ Setting タブ（見た目の設定）**

テキストの色やフォントをカスタマイズします。

#### **■ テキストカラー設定 (TextColorSetting)**

* **TextBase**: タイマー以外の汎用テキスト（タイトルや走者名）の色。  
* **Timer**: タイマー稼働中の色。  
* **TimerStop**: タイマーを停止させた時の色。

#### **■ フォント設定 (TextFontSetting)**

* 自動生成されたテキストの **フォント種類・サイズを一括変更** できます。  
* **Outline**: 縁取り（アウトライン）の有無、太さ、色を設定可能です。  
* ※現在のバージョンではグラデーション設定には対応していません。

## **⚠️ 注意事項・仕様**

* **動作確認**: OBS 32.0.2 | なるべくOBS 30.0以上のバージョンで使うことを推奨しています。一応古いテキストのバージョンにも対応はしていますが保証はしません。
* **対応OS**: Windows (64bit)  
* **文字コード**: JSONファイルは必ず **UTF-8** で保存してください。
