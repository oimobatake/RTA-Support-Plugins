# **RTA Support Plugin**

OBS Studio上でRTAイベント等の進行を支援するためのプラグインです。

「NodeCGでレイアウトとか用意するほどじゃないな…」 とか 「NodeCGとかわかんないけどあんな感じにサクッと情報変更したいな」
みたいな時に使えるようなものを目指して作りました。

タイマー操作、テキストソースの自動生成、スケジュールの管理を一括で行うことができます。

## OBS へのインストールと配置

### 概要
プラグイン本体（ビルド済みのファイル）を OBS のプラグインフォルダに置き、オーバーレイ表示用の `index.html` とプラグインが生成する `overlay_data.json` を同じフォルダに置くか、Browser ソースから参照します。

### プラグイン本体の配置
1. OBS を終了します（必須）。  
2. ビルド済みプラグインファイル（Windows: `*.dll` ／ macOS/Linux: `*.so` 等）を OBS のプラグインフォルダにコピーします。  
   - Windows: - 64bit: `C:\Program Files\obs-studio\obs-plugins\64bit\`   
3. OBS を再起動し、プラグインの UI（Dock）や設定が表示されることを確認します（メニューの「ドック」などを確認）。

※ 普段使っているシーンコレクションとは別に専用のシーンコレクション内で扱うことをお勧めします。

# Main タブ

概要
- 配信中のタイマー制御（カウントアップ / カウントダウン）、走者情報の編集、スケジュールの前後移動を行います。

操作手順（ユーザ向け）
1. タイマー表示を確認する（形式: HH:mm:ss）。  
2. 「Start」ボタンでタイマーを開始。開始時に自動でスクリーンショットを撮る設定が有効なら撮影されます。  
3. 「Stop」ボタンでタイマーを停止。停止時の視覚表示（色など）は設定に応じて変わります。  
4. 「Reset」ボタンでタイマーを初期化（カウントアップを 00:00:00、カウントダウンを設定した初期値へ）。  
5. 表示モード（カウントアップのみ / カウントダウンのみ / 両方 / 非表示）はラジオボタンで切り替えます。  
6. ▲ / ▼ ボタン、またはゲーム選択ドロップダウンでスケジュール内のゲームを選択し、入力欄に読み込みます。  
7. ゲーム情報（タイトル、カテゴリ、プラットフォーム、見積時間など）を編集できます。  
8. 各走者の「Stop」ボタンは、その時点のタイムを個別に記録するのに使います（カウントアップ表示時に有効）。  
9. 完了したら「done」ボタンで現在の入力内容を保存してオーバーレイに反映します。

注意
- 変更は保存されオーバーレイ側に反映されます。配信前に動作確認してください。  
- 自動スクリーンショット機能を使う場合、OBS の保存先や権限設定を事前に確認してください。


# Schedule タブ

概要
- 外部 JSON 形式のスケジュールを取り込み、列の対応付け、表形式での編集、内部スケジュールへの反映とエクスポートを行います。

操作手順
1. 「...」ボタンでスケジュール JSON ファイルを選択して読み込みます。  
2. 読み込み後、画面下部の「Column Format」で各表示項目（GameTitle / Category / Platform / RunnerName / Commentator）に対応する列を選択します。自動候補が入る場合がありますが、必要に応じて手動で修正してください。  
3. 「apply」を押すと選択したマッピングでデータが取り込まれ、内部のスケジュール一覧に反映されます。  
4. 表の内容は「Add」「Remove」で編集可能。「Update」で表の内容を確定し、内部スケジュールに反映します。  
5. 編集済みのスケジュールは「Export」で JSON として保存できます（他環境への移行やバックアップに便利です）。

注意
- 取り込み対象の JSON は列名と行データを持つ構造が前提です。想定外の形式の場合は手動でマッピングしてください。  
- 見積時間は秒単位で保持され、画面表示では時分秒に変換されます。


# Design タブ

概要
- 配信画面に表示するテキスト要素（ゲームタイトル、走者名、タイマー等）の位置・フォント・色・表示/非表示などをレイアウト単位で編集し、保存／読み込みします。

操作手順
1. 画面上部の「SceneLayoutSetting」エリアで編集するレイアウト（例：main、setup）を選択します。  
   - 「Add」：現在のレイアウトを複製して新規作成。  
   - 「Delete」：選択中レイアウトを削除（確認あり）。  
   - 「SaveLayout」：選択中レイアウトを外部 JSON としてエクスポート（バックアップ用）。  
   - 「LoadLayout」：外部 JSON をインポートして座標・スタイルを適用。  
2. 「SyncSceneChange」を有効にすると、選択したレイアウト名と同名の OBS シーンが存在すれば自動でそちらに切り替える動作を試みます。OBS に同名のシーンがあることをご確認ください。  
3. 「TextName」または要素選択のドロップダウンで、編集対象のテキスト要素を選びます（選択後、下の各設定に現在値が読み込まれます）。  
4. フォントと色を設定します：  
   - 「TextFont」ボタンでフォント（種類・サイズ・太字・斜体）を選択。  
   - 「TextColor」ボタンで文字色を指定。  
5. 位置と整列を設定します：  
   - 「TextPosition」で X / Y の数値を入力して表示位置を調整（小数可）。  
   - 整列は「左揃え／中央揃え／右揃え」から選択。  
6. 縁取りを設定します：  
   - 「outline」を有効にし、太さと色を指定して文字の視認性を向上できます。  
7. 幅と折返しを設定します：  
   - 「TextMaxWidth」で最大幅（px）を指定（0 は制限なし）。  
   - 「WrapMode」で「None（無制限）」「Shrink（必要に応じて縮小）」「Wrap（自動改行）」のいずれかを選択。  
8. 変更は保存されオーバーレイに反映されます。必要に応じて「SaveLayout」で外部ファイルに書き出してバックアップしてください。

注意
- 座標やフォントの極端な変更は表示崩れの原因になります。変更は少しずつ行い、オーバーレイで確認しながら調整してください。  
- レイアウト名を OBS のシーン名と揃えると自動切替が利用しやすくなります。


# Global タブ

概要
- プラグイン全体に影響する表示オプションや自動スクリーンショット等の設定を行います。

操作手順
1. アイコン表示の切替：表示エリアで `Runner1_Icon` / `Runner2_Icon` / `Runner3_Icon` / `Runner4_Icon` / `Commentary_Icon` の各チェックボックスを ON/OFF します。  
2. 自動スクリーンショットの設定：`AutoScreenShotFlag` の下にある `TimerStart` / `TimerStop` のチェックを使い、タイマー開始時・停止時に自動でスクリーンショットを撮るかを設定します。  
3. 停止時の色設定：`TimerStopColor` ボタンで、タイマー停止状態を示す色を選択できます。  
4. 手動スクリーンショット：`ScreenShot` ボタンを押すと任意のタイミングでスクリーンショットを撮影できます。

注意
- これらの設定は保存され、次回起動時にも保持されます。  
- 自動スクリーンショットを有効にする場合は、OBS 側の保存先やファイル命名、ディスク容量に注意してください。


# セットアップ（index.html 配置とデータ保存場所について）

概要
- オーバーレイ表示用の `index.html`（と関連ファイル）をどこに置けばよいか、プラグインが保存するデータファイルの場所（目安）と確認方法をまとめます。

配置場所
- `index.html` は、オーバーレイ側で配信画面を表示するために用意するファイルです。`index.html` とオーバーレイが参照する `overlay_data.json` は同じフォルダに配置してください。  

overlay_data.json の置き場所
- プラグインは実行環境に応じた「プラグイン設定フォルダ」に `overlay_data.json` を作成します。代表的な例は次の通りです（環境によって異なります）：
  - Windows（例）: `%APPDATA%\obs-studio\plugin_config\<プラグイン名>\overlay_data.json`  
- 実際の作成場所は環境や OBS の設定に依存します。初回は UI 操作で保存を行うとファイルが生成されるので、その後ファイル検索で場所を確認してください。

index.html の配置と OBS での読み込み
1. `index.html` と`overlay_data.json`を同じフォルダに配置します。  
2. OBS で新規に「Browser」ソースを追加し、ローカルファイルとして `index.html` を指定します（Local File にチェック）。  

バックアップとトラブルシュート
- 重要ファイル：`overlay_data.json` と外部にエクスポートしたレイアウト JSON。編集前にバックアップを取りましょう。  
- 見つからない場合：一度プラグインの UI 上で保存操作を行い、その後 OS のファイル検索で `overlay_data.json` を探してください。  
- ブラウザがデータを読み込まないときは、`index.html` と `overlay_data.json` が同じフォルダにあるか、Browser ソースのパスが正しいか確認してください。
